A small label that categorises an item.

**You provide:** `<span class="gr-tag">` with text, and optionally one colour (`gr-tag--green`, `--blue`, `--orange`, `--accent`) or `gr-tag--pill` for dates and counts.

- Neutral is the default. Use colour only when the category matters at a glance, such as unread or priority items.
- Keep to one or two words, sentence case.
- `gr-tag--accent` is the strongest; use it for one category only (for example "Important").
- Tags are not buttons. For a clickable filter, use a small secondary button.
